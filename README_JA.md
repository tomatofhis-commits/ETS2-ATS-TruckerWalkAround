# TruckerWalkAround (v1.0-beta) - 日本語ドキュメント

**American Truck Simulator (ATS) & Euro Truck Simulator 2 (ETS2) 向け 物理歩行プラグイン**

[**English README (英語版はこちら)**](README.md)

---

## 🌟 概要

**TruckerWalkAround** は、トラックの運転席から降りて、ゲームの世界をリアルな物理演算（段差昇降・衝突判定・重力）とともに自由に歩き回ることができる外部連携型ウォーキングプラグインです。

従来の常駐型MODとは異なり、専用ランチャー（`TruckerWalkAround.exe`）が起動している間だけプラグインが配置され、ランチャーを閉じると自動的に完全消去されます。ゲームの大型アップデート時にクラッシュを引き起こす心配がありません。

---

## ✨ 主な特徴

- **PhysX物理エンジン直結**: ゲーム内のコライダーとリアルタイムでRaycast（当たり判定）を行い、地面の傾斜や最大0.45mの段差・縁石の昇降、落下判定を実現。
- **ATS / ETS2 専用バイナリ設計**: 各ゲームのメモリ構造に合わせて最適化された2つのプラグイン（`TruckerWalkAround_ATS.dll` / `TruckerWalkAround_ETS2.dll`）を自動で振り分け配置。
- **`config.cfg` の自動調整機能**: ランチャー起動時に、歩行カメラに必要な `uset g_developer "1"` および `uset g_console "1"` を自動設定・維持。手動で設定ファイルを編集する必要はありません。
- **車両操作の自動ロック**: 歩行モード中は、トラックの操作系（WASD・ステアリング・アクセル・サイドブレーキ等）を自動ブランク化。歩行中の誤発進を防止します。
- **HUD・通知の自動非表示**: 歩行中はルートアドバイザーやポップアップ通知を自動で隠し、高い没入感を提供。
- **スタック脱出用Noclip機能**: ガードレールや溝などにはまって動けなくなった場合、`[Alt]` キーを押すことで空中浮遊・すり抜けモードへ即座に移行し、安全に脱出可能。

## 🎮 操作方法ガイド

| キー | 機能 | 説明 |
| :--- | :--- | :--- |
| **`[F9]`** | **歩行モード切替** | 運転席視点と物理歩行モードを切り替えます。 |
| **`[BackSpace]`** | **緊急脱出** | 歩行モードを即座に終了し、運転席へ復帰します。 |
| **`[W] [A] [S] [D]`** | **移動** | 前後左右へ移動します。 |
| **`[Shift]`** | **ダッシュ** | 移動速度をアップします。 |
| **`[Alt]`** | **Noclip切替** | 壁抜け・空中浮遊モード（スタック脱出用）を切り替えます。 |
| **`[Space]`** | **上昇** | Noclipモード中に上昇します。 |
| **`[Ctrl]`** | **下降** | Noclipモード中に下降します。 |
| **`[F10]`** | **モニター切替** | 物理コライダーや座標のリアルタイム表示を切り替えます。 |
| **マウス移動** | **視点回転** | 周囲を見渡す自由視点操作。 |

## 🚀 使い方

1. [**Releases**](../../releases) から最新のインストーラー `TruckerWalkAround_Setup_v1.0_beta.exe` をダウンロードしてインストールします。
2. インストール後、**TruckerWalkAround** を起動します。
   - ATS / ETS2 のフォルダおよび `config.cfg` が自動検出され、必要な設定とプラグイン配置が行われます。
3. そのまま Steam 等からゲームを通常起動します。
4. ゲーム内で **`[F9]`** キーを押すと、トラックから降りて歩行モードになります。
5. ゲーム終了後、**TruckerWalkAround** のウィンドウを閉じると、配置されたプラグインは自動削除されます。

## ⚠️ 注意点・Tips

1. **駐車場の静的車両などの当たり判定について**:
   - 街中や駐車場・PAに最初から背景（プロップ）として配置されている一部のオブジェクトや駐車車両には、ゲームエンジンの仕様上コライダーが存在しない場合があります。これらをすり抜けることがありますが不具合ではありません。
2. **隙間や地形にはまって動けなくなった場合**:
   - ガードレールや狭い隙間等にはまってスタックした場合は、**`[Alt]`** キーを押して「Noclipモード」に切り替えて脱出してください。脱出後、再度 **`[Alt]`** キーを押すことで通常の物理歩行に戻ることができます。
   - また、**`[BackSpace]`** キーを押すことで、いつでも即座にトラックの運転席へ戻ることができます。

## 🛡️ セキュリティとウイルス誤検知について

本ツールはゲームプロセスのメモリ（PhysX・カメラ・CVar等）を直接読み書きし、ゲームフォルダへ `.dll` を自動配置するため、一部のアンチウイルスソフト（ヒューリスティックAI検知）で「身元不明のアプリ」として警告が出る場合があります。

本ソフトウェアには悪意のあるコードは一切含まれておらず、VirusTotal において世界70社以上のセキュリティエンジンで安全性が確認されています：
- **VirusTotal スキャン結果**: [公開スキャンレポート (v1.0-beta)](https://www.virustotal.com/gui/file/9053e54dba6868b5638388e58e0c6b8974dda52b26e924f77f25e7a9a2402576)
- *Microsoft Defender、Kaspersky、Symantec、Bitdefenderなどの主要ベンダーを含む約70社でClean判定です。*

## 🛠️ ソースコードからのビルド方法

### 必要環境
- Visual Studio 2022 / Build Tools (MSVC x64 コンパイラ `cl.exe`)
- .NET Framework 4.0+ (`csc.exe`)
- [Inno Setup 6](https://jrsoftware.org/isdl.php) (インストーラーをビルドする場合)

### ビルド実行
Visual Studio の「x64 Native Tools Command Prompt」から以下を実行します：
```cmd
# 1. ATSおよびETS2専用DLLをコンパイル
build_dll.bat

# 2. C# WinForms ランチャーおよびインストーラーを一括ビルド
build_all.bat
```
