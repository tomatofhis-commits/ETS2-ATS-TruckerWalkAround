================================================================================
TruckerWalkAround - 更新履歴 / Change Log
================================================================================

■ 2026-11-13 : v1.0.2
--------------------------------------------------------------------------------
【新機能・不具合修正】
1. 起動時パターン（AoB）スキャン方式の導入
   - ゲーム起動時にメモリ上のパターンからシーンフォーカス関連アドレスを自動検出する方式へ刷新。
   - 1.62.1 / 1.62.2 / 1.62.3 などのマイナーアップデートによるアドレスズレを自動吸収し、車から離れても地面や障害物を正常に認識するよう修正。
   - 1.63 以上のメジャーアップデート時はランチャー側で検知してプラグイン配置を安全に停止します。


■ 2026-11-12 : v1.0.1
--------------------------------------------------------------------------------
【新機能・改善点】
1. 歩行モード移行（F9キー）の安全ガード機能
   - デスクトップUI（メインメニュー、ガレージ管理画面、マップ等）でF9を押しても歩行モードに入らないよう完全ロック。
   - パーキングブレーキ（手ブレーキ）が引かれている場合のみ歩行モードへの突入を許可。
   - 走行画面（実車運転状態）かつパーキングブレーキONの2重条件を満たした時のみ歩行可能に改善。
   - SCS Telemetry SDK の pause / start イベント監視に加え、UIマウスカーソル検知による確実な走行状態判別を導入。

2. Noclip切替（Altキー）の制御改善
   - AltキーによるNoclip（壁抜け・空中浮遊）切替を歩行中のみに限定。
   - 通常運転中のAltキー誤作動を完全に防止。

3. 外部契約（World of Trucks）オートセーブの安全性向上
   - トラック本体の物理座標を変更せず、独立した物理シーンクエリ（focus2 / region_query）とRaycastにより当たり判定を維持するアーキテクチャを確立。
   - 外部契約中のオートセーブ発生時にもトラックが変な場所に保存されず、安全に停止位置に復帰できるよう最適化。

4. アプリケーションアイコンの刷新
   - 公式アイコン（TWA.ico）をランチャー本体およびインストーラーに正式適用。


■ 2026-11-08 : v1.0-beta (Beta 1.0)
--------------------------------------------------------------------------------
【初期リリース】
- American Truck Simulator (ATS) および Euro Truck Simulator 2 (ETS2) 向け自由歩行プラグインの初回公開。
- PhysX 物理エンジンと直接連動した高精度な歩行判定（段差昇降・縁石・壁スライド・衝突）。
- 歩行中の車両操作自動ロック機能（誤発進防止）。
- ルートアドバイザー等のHUD自動非表示機能。
- 外部マネージャー（TruckerWalkAround.exe）によるゲーム起動時のみのプラグイン一時配置・安全管理機構。
- config.cfg（g_developer / g_console）の自動検出・自動設定機能。
